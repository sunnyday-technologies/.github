# Sunnyday Technologies

Sunnyday Technologies is a materials and manufacturing technology company in Wisconsin, USA. We develop open hardware, engineering data standards, CAD validation tools, and decision-support software for additive manufacturing.

## How the projects fit together

CEMFORGE supports formulation decisions, M3-CRETE provides an open printing platform, and Open3DCP standardizes the resulting materials and process data. CADCLAW validates CAD assemblies, while MARB uses automated grading to benchmark AI-generated mechanical assemblies. TOPOCRETE explores concrete-aware topology optimization. PARAMAT3D and OpenSpool extend the portfolio into desktop-additive-manufacturing materials and spool identification.

## Install / try

- `pip install cadclaw` — [`cadclaw` on PyPI](https://pypi.org/project/cadclaw/)
- `git clone https://github.com/sunnyday-technologies/M3-CRETE` — printer CAD and BOM
- `git clone https://github.com/sunnyday-technologies/Open3DCP` — public data schema and documentation (the repository does not supply a dataset)
- `git clone https://github.com/sunnyday-technologies/MARB` — AI-CAD assembly benchmark
- `git clone https://github.com/sunnyday-technologies/TOPOCRETE` — concrete topology optimization
- `git clone https://github.com/sunnyday-technologies/paramat` — FFF filament print conditions
- `git clone https://github.com/sunnyday-technologies/OpenSpool` — RFID conventions for filament spools
- CEMFORGE — request access at [cemforge.ai](https://cemforge.ai)
